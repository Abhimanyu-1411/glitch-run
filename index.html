GLITCH RUN — Neon Cyberpunk Endless Runner

GLITCH RUN is a free browser-based endless runner game with a neon cyberpunk aesthetic. Built entirely with HTML5 Canvas and vanilla JavaScript — no downloads, no plugins, no server required.

Gameplay

Run endlessly through a procedurally generated world. Dodge triangle-spike obstacles, collect glowing data fragments to earn coins, and survive as long as possible. Your distance score and fragment count determine your rank.

Power-Ups

  • Shield — absorbs one collision
  • Slow-Mo — slows the world for easier navigation
  • Data Magnet — attracts nearby data fragments automatically

Glitch Events

  • Data Storm — surge of extra fragments to collect
  • Speed Surge — obstacles accelerate temporarily
  • Gravity Error — heavier gravity affects your jump
  • Corrupt Display — visual glitch distortion effect

Controls

  • Jump: Space, W, or Up Arrow (tap the screen on mobile)
  • Fast-Drop: Down Arrow or S while airborne (swipe down or tap the drop button on mobile)
  • Pause: P or Escape

Features

  • Cosmetic shop with skins and trails, purchasable with in-game coins
  • 11 achievements with persistent progress
  • 3 rotating daily missions with coin rewards
  • Synthesized synthwave background music (no external audio files)
  • Full settings: Sound Effects, Background Music, Screen Shake, Reduced Motion
  • Mobile-friendly with touch controls
  • All progress saved automatically in your browser
